Hold-shape editor

Edit modeDrag a vertex to move it. Hover an edge and a + appears — drag it to insert a vertex there. Drag inside the outline to move the whole shape. Right-click a vertex to delete it. Click another hold's outline to switch to it.
Draw modeClick around the hold to append points (need ≥3).
n / pnext / previous hold
e / dedit / draw mode
arrowsnudge the selected vertex 0.05% — shift 0.5%, alt 0.01%. With nothing selected, nudges the whole outline.
tab / shift+tabselect next / previous vertex
deldelete the selected vertex
ctrl+Z / ctrl+shift+Zundo / redo
c / rclear this outline / revert it to the loaded file
wheelzoom at the cursor · space-drag or middle-drag to pan · 0 fit · f zoom to hold
ctrl+Ssave the file copy (writes straight to it once you've used Link file…, otherwise downloads)
ctrl+shift+PPublish → live: writes the outlines to the board row in Supabase, so every phone picks them up on its next load. Needs an admin sign-in once per browser. No commit, no deploy.

Outlines are stored as % of the board image, against the live board version in __meta.board_updated_at; the app ignores any set that doesn't match the live board. Hold positions come from the live board map and are never changed here. Progress auto-saves to this browser — nothing reaches anyone else until you Publish. Export JSON / Link file… are for refreshing app/hold_shapes.json, the copy that ships with the app as its offline fallback; worth committing now and then, but the live board is what people see.
